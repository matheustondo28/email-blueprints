# TWOJEYS storefront concept

A redesign concept for the TWOJEYS storefront. Static HTML, CSS and vanilla JS, no build step: open `index.html`.

What works: category and finish filters, sorting, search, saved pieces, product view with finish and size selection, bag drawer with quantity editing and a free-shipping progress bar. Bag and saved pieces persist in `localStorage`.

What is placeholder: product names, prices, policies (shipping threshold, returns, repairs) and journal entries are invented for the concept. Jewelry visuals are SVG illustrations standing in for photography. Checkout is not connected.
